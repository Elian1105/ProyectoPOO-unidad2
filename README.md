ProyectoPOO-unidad2
Descripción del Proyecto
Este proyecto consiste en un sistema de gestión de contenido audiovisual desarrollado en Java utilizando Programación Orientada a Objetos (POO). Permite administrar diferentes tipos de contenido audiovisual mediante una jerarquía de clases basada en herencia, abstracción y relaciones entre objetos.

Objetivos del Proyecto
Aplicar los principios de la Programación Orientada a Objetos.
Implementar una clase abstracta base para reutilizar código.
Utilizar herencia, asociación y agregación entre clases.
Gestionar diferentes tipos de contenido audiovisual.

Instalación y Ejecución
Requisitos

Ejecución

Abrir Eclipse.
Importar el proyecto.
Ejecutar la clase:
PruebaAudioVisual.java
Seleccionar:
Run As → Java Application
